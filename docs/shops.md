## 🛠️ 3. Для самостоятельной сборки (DIY)

Для тех, кто готов к пайке и хочет кастомизированное устройство.

### Проект FakeTec

Открытый проект для сборки устройства на базе энергоэффективного чипа **NRF52840**.

* **Ссылки на проект:** [GitHub (gargomoma/fakeTec\_pcb)](https://github.com/gargomoma/fakeTec_pcb)
* **Преимущества:** Бюджетное решение с низким энергопотреблением

#### Обязательные компоненты

| :--------------------- | :-------------------------------------------------------------------------------------------------------------- | :----- | :----------------------------------------------------------------------------------------------------- |
| **NRF52840 nice!nano** | Основной контроллер                                                                                             | 220 ₽  | [Aliexpress](https://aliexpress.ru/item/1005007383270623.html)                                         |
| **HT-RA62**            | LoRa-модуль для радиосвязи                                                                                      | 350  ₽ | [OZON](https://www.ozon.ru/product/ht-ra62-modul-serii-lora-sx1262-vtorichnaya-razrabotka-2197829350/) |
